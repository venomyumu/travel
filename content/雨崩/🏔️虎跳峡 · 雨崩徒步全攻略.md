## 📅 前期准备与交通

### ✈️ 抵达路径
机票1157r
1. **长沙 → 丽江(5/3)**：预计2h，住宿古城南门（机场大巴）
2. **丽江 → 虎跳峡 → 飞来寺(5/4)**：中虎跳张老师客栈拼车（249r）,住宿飞来寺
3. **飞来寺 → 尼农(5/5)**：拼车前往西当徒步起点。
4. **尼农 → 上雨崩(5/5)**：住宿上雨崩（行者山舍131r X 2晚）
5. **上雨崩 → 冰湖(5/6)**：住宿上雨崩
6. **上雨崩 → 下雨崩 → 神瀑 → 出村 -> 香格里拉(5/7)**：出村迪庆交运大巴（末班车16：30，预计4h），住香格里拉
7. **香格里拉 -> 丽江 -> 长沙(5/8)**：香格里拉高铁(63r) ->(1h20m) 丽江站 ->(40m) 三义机场

### 🎒 装备清单(轻装)

- [x] **鞋靴**：高帮防水登山鞋。 
    
- [x] **服装**：冲锋衣裤（硬壳）、羽绒内胆、速干衣、厚登山袜。 
    
- [x] **工具**：登山杖（双杖）、头灯、充电宝（3C）、38L小鹰背包。 
    
- [x] **药品**：布洛芬、创可贴、葡萄糖口服液。

## 📍 核心路线详解

### 1. 冰湖路线 (Ice Lake)

> [!abstract] 关键信息
> 
> - **距离**：往返约 12km
>     
> - **爬升**：约 700m
>     
> - **贴士**：经过笑农大本营时可稍作休息，最后一段碎石坡较陡。
>     

### 2. 神瀑路线 (Sacred Waterfall)

> [!todo] 朝圣体验
> 
> - 这是雨崩最神圣的路线，藏民相信在瀑布下淋水可以洗净罪孽。
>     
> - 全程水泥路或平整土路较多，难度适中。
>     

### 3. 出山：尼农峡谷

> [!warning] 注意安全
> 
> - 尼农线虽多为下坡，但一边是峭壁一边是深谷。
>     
> - **严禁**在雨天走此路，会有落石风险。
>
